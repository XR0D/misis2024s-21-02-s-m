### Теория

### Метод Бернсена для бинаризации изображений

**Описание**: Метод Бернсена — это адаптивный алгоритм бинаризации, который использует локальные характеристики контраста для преобразования серых изображений в бинарные.

**Основные шаги**:

1. **Локальные минимумы и максимумы**:
   - Для каждого пикселя вычисляются минимальное и максимальное значения яркости в окне радиуса \(r\) вокруг него.

2. **Вычисление контраста**:
   - Контраст определяется как \(C = I_{max} - I_{min}\).

3. **Установка порога**:
   - Если \(C > C_{min}\):
     - Порог \(T\) устанавливается как \((I_{min} + I_{max}) / 2\).
   - В противном случае порог может быть фиксированным.

4. **Бинаризация**:
   - Пиксель становится белым (\(255\)), если его значение больше порога \(T\), и черным (\(0\)) в противном случае.

**Преимущества**:
- Адаптивность к локальным условиям освещения.
- Гибкость в настройке параметров.

**Недостатки**:
- Чувствительность к шуму.
- Зависимость от правильного выбора параметров.

**Применение**: Идеален для изображений с переменным освещением, используется в OpenCV для улучшения качества бинаризации.

### Метод Ниблака для бинаризации изображений

**Описание**: Метод Ниблака — это адаптивный алгоритм бинаризации, который использует локальное среднее и стандартное отклонение для определения порога бинаризации в каждом пикселе.

**Основные шаги**:

1. **Определение локального окна**:
   - Для каждого пикселя вычисляется среднее значение (\(m\)) и стандартное отклонение (\(std\)) яркости в окне радиуса \(r\).

2. **Установка порога**:
   - Порог \(T\) для бинаризации вычисляется как:
     \[
     T(x, y) = m + k \cdot std + d
     \]
   - Здесь \(k\) — коэффициент, который регулирует влияние стандартного отклонения, а \(d\) — смещение.

3. **Бинаризация**:
   - Пиксель становится белым (\(255\)), если его значение больше порога \(T\), и черным (\(0\)) в противном случае.

**Параметры**:
- **\(r\)**: радиус окна для вычисления локальных статистик.
- **\(k\)**: коэффициент, который определяет, насколько стандартное отклонение влияет на порог.
- **\(d\)**: смещение, добавляемое к порогу.

**Преимущества**:
- Адаптивность к локальным условиям освещения и контрасту.
- Хорошо работает на изображениях с неоднородным освещением.

**Недостатки**:
- Чувствительность к шуму, особенно в областях с низким контрастом.
- Зависимость от выбора параметров \(k\) и \(d\) для достижения оптимального результата.

**Применение**: Широко используется в задачах обработки изображений для выделения объектов на фоне с переменным освещением, например, в медицинской визуализации и анализе изображений.

### Основные понятия для оценки детекции объектов

1. **Истинные положительные (TP)**:
   - Количество правильно обнаруженных объектов. Это случаи, когда детектор правильно идентифицировал объект, который действительно присутствует в изображении.

2. **Ложные положительные (FP)**:
   - Количество объектов, которые были ошибочно обнаружены детектором. Это случаи, когда детектор идентифицировал объект, но на самом деле его не было.

3. **Ложные отрицательные (FN)**:
   - Количество объектов, которые не были обнаружены детектором, хотя они действительно присутствовали в изображении. Это случаи, когда детектор пропустил существующий объект.

### Критерий IoU (Intersection over Union)

- **IoU** — это метрика, используемая для оценки качества детекции. Она вычисляется как отношение площади пересечения предсказанного bounding box (рамки) и истинного bounding box к площади их объединения:
  
  \[
  \text{IoU} = \frac{\text{Area of Overlap}}{\text{Area of Union}}
  \]

### Генерация тестового изображения

Программа создает тестовое изображение размером 297x297 пикселей, состоящее из нескольких кругов различного цвета и радиуса. Круги располагаются в разных частях изображения, что позволяет создать разнообразные визуальные элементы для дальнейшей обработки.

После генерации тестового изображения программа применяет два различных фильтра:

1. **Первый фильтр** использует ядро, которое выделяет разницу между соседними пикселями. Это позволяет выявить границы объектов на изображении.

2. **Второй фильтр** основан на транспонированном ядре, что также помогает в выделении границ, но изменяет акценты в результатах фильтрации.

Результаты фильтрации отображаются в отдельных окнах, предоставляя возможность визуально оценить, как каждый фильтр влияет на исходное изображение.

Для объединения результатов фильтрации по двум направлениям программа вычисляет корень суммы квадратов значений, полученных из двух фильтров. Это позволяет создать комбинированное изображение, которое более полно отражает границы объектов.

### Создание цветного изображения

После обработки результаты фильтрации объединяются в трехканальное цветное изображение. Каждый канал соответствует результатам фильтрации по двум направлениям и их производной. Это дает возможность визуально оценить различные аспекты обработки и выделить детали, которые могут быть неочевидны в черно-белом изображении.

### Теория

### Метод детектирования объектов с использованием преобразования Хафа

**Что это такое**: Метод преобразования Хафа — это способ нахождения фигур, таких как линии и круги, на изображениях.

**Как работает**:
1. **Голосование**: Каждый пиксель (например, пиксель края объекта) "голосует" за параметры формы (например, где находится центр круга и какой у него радиус).
2. **Параметрическое пространство**: Все голоса собираются в специальное пространство, где каждая ось соответствует разным параметрам (например, координаты центра круга и его радиус).
3. **Находим фигуры**: Параметры, которые получили больше всего голосов, считаются найденными фигурами.

**Почему это полезно**:
- Хорошо работает даже при наличии шума.
- Помогает находить определенные формы на изображении.

**Где применяется**: Используется для распознавания кругов, линий и других фигур в задачах обработки изображений и компьютерного зрения.

# Отчет по 7 ЛР

### Цель

Изучить и реализовать метод сегментации изображений. Рассмотреть возможные варианты оценки качества сегментации с использованием эталонной разметки и реализовать функционал для этого.

### Теория

### Edge-Based сегментация объектов изображения

**Описание**: Edge-Based сегментация — это метод обработки изображений, который фокусируется на выявлении границ (или краев) объектов на изображении. Этот подход основан на использовании изменений яркости в изображении, что позволяет выделить контуры объектов.

**Как работает**:
1. **Выделение границ**: Используется фильтр Кэнни, который определяет границы, основываясь на градиенте изображения. Границы представляют собой участки с резкими изменениями яркости.
2. **Поиск контуров**: После выделения границ применяются алгоритмы для поиска контуров, которые представляют собой замкнутые линии, описывающие объекты на изображении.

Edge-Based сегментация объектов изображения позволяет эффективно выделять объекты на основе их границ, а использование метрик, таких как IoU, Precision, Recall и F1 Score, помогает количественно оценить качество сегментации и эффективность алгоритмов обработки изображений.

### Метрики для оценки качества сегментации

### 1. **Intersection over Union (IoU)**:
   - **Что это**: IoU — это метрика, которая измеряет, насколько хорошо предсказанная область (например, обнаруженный объект) совпадает с истинной областью (ground truth). Это важный показатель в задачах сегментации и детекции объектов.
   - **Зачем используется**: IoU помогает оценить, насколько точно модель определяет объекты на изображении по сравнению с реальными объектами, что критично для оценки качества работы алгоритмов компьютерного зрения.

### 2. **Precision (Точность)**:
   - **Что это**: Precision показывает, насколько правильно модель идентифицирует объекты. Это доля правильно предсказанных объектов (истинно положительных) среди всех объектов, которые модель предсказала как положительные.
   - **Зачем используется**: Precision дает понимание о том, насколько точны предсказания модели. Высокая точность означает, что большинство предсказанных объектов действительно являются объектами, которые мы ищем.

### 3. **Recall (Полнота)**:
   - **Что это**: Recall измеряет, насколько хорошо модель находит все истинные объекты. Это доля правильно предсказанных объектов среди всех объектов, которые действительно существуют в данных.
   - **Зачем используется**: Recall позволяет оценить, насколько хорошо модель захватывает все объекты в изображении. Высокая полнота означает, что модель успешно находит большинство истинных объектов, даже если это приводит к увеличению ложных срабатываний.

### 4. **F1 Score (F1-мера)**:
   - **Что это**: F1 Score — это метрика, которая объединяет точность и полноту в одно число. Она помогает оценить баланс между ними, особенно когда важно учитывать как ложные положительные, так и ложные отрицательные предсказания.
   - **Зачем используется**: F1 Score полезен, когда необходимо найти баланс между точностью и полнотой, особенно в ситуациях, когда важно не только точно идентифицировать объекты, но и не пропускать их.

### Теория

### linRGB

**linRGB** (линейное RGB) — это цветовое пространство, в котором цвета представлены в линейной форме, без гамма-коррекции. Это позволяет более точно моделировать физические свойства света и улучшает точность вычислений в графике и обработке изображений.

### Плотность цветового распределения

**Плотность цветового распределения** — это мера, показывающая, как часто встречаются различные цвета в изображении. Она отображает количество пикселей определенного цвета и помогает визуализировать, какие цвета преобладают в изображении, что полезно для анализа цветовой информации и коррекции цвета.

### Цель

Целью лабораторной работы является изучение метода цветокоррекции по методу **Grey World** и оценка качества полученного изображения. Метод Grey World предполагает, что средний цвет сцены близок к серому, и корректирует цвета в изображении для достижения этого баланса.

### Ход работы

Изучили и реализовали метод Gray World который вычисляет среднее значение цветовых каналов (RGB) изображения и корректирует каждый канал так, чтобы достичь серого баланса.

### Вывод

![2](prj.lab/lab09/2.png "lab09")


1. **Mean Absolute Error (MAE)**: 
   - Значение: 16.3808
   - Описание: Среднее абсолютное отклонение между исходным и исправленным изображениями. Это средняя величина разницы между соответствующими пикселями двух изображений. Более низкое значение MAE означает, что исправленное изображение ближе к исходному.

2. **Peak Signal-to-Noise Ratio (PSNR)**:
   - Значение: 26.3392 dB
   - Описание: Пиковое отношение сигнал-шум. Это метрика, которая показывает соотношение между максимально возможным сигналом и уровнем шума. Более высокое значение PSNR означает лучшее качество изображения. Значение 26.3392 dB является относительно низким, что указывает на наличие заметных различий между исходным и исправленным изображениями.

3. **Structural Similarity Index (SSIM)**:
   - Значение: 1
   - Описание: Структурное сходство. Это метрика, которая оценивает сходство структурных характеристик между исходным и исправленным изображениями. Значение 1 означает полное сходство, то есть исправленное изображение полностью идентично исходному.

Эти метрики показывают, что исправленное изображение довольно близко к исходному, но все же есть заметные различия. Высокое значение SSIM (1) указывает на то, что структурные характеристики изображений практически идентичны, но более высокие значения MAE и относительно низкий PSNR свидетельствуют о наличии различий в цветопередаче и контрасте.
