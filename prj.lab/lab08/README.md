# Отчет по 8 ЛР

### Цель

Изучить плотность цветового распределения и визуализировать это в linRGB.

### Ход работы

В ходе лабораторной работы было создано консольное приложение для визуализации плотности распределения цветов в пространстве linRGB.

Приложение работает с цветовым кубом RGB, в котором через точку (0.5, 0.5, 0.5) проходит плоскость, перпендикулярная вектору (1, 1, 1). Каждый цвет проецируется на эту плоскость из точки (0, 0, 0).

### Работа консольного приложения

Для запуска исполняемого приложения, нужно найти исполняемый файл в вашей директории и прописать в консоль:

```.\lab08.exe <input> <output> <size>```

input - Путь изображения для визуализации плотности

output - Путь сохранения изображения

size - Размер изображения
