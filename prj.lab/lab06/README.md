# Отчет по лабораторной работе

### Цель

Изучить и реализовать методы детектирования объектов на изображениях с использованием преобразования Хафа. Рассмотреть возможность оценки качества детектирования с помощью анализа FROC (Free-Response Operating Characteristic) и визуализировать результаты работы алгоритмов.

### Ход работы

В ходе выполнения лабораторной работы была разработана программа, которая генерирует тестовое изображение с заданными параметрами и реализует функционал для детектирования кругов на изображениях. Программа также включает методы бинаризации изображений, такие как метод Ниблака, и предоставляет возможность визуальной настройки параметров через GUI.

### Работа консольного приложения

Для запуска консольного приложения необходимо найти исполняемый файл в вашей директории и ввести в консоль следующую команду:

```bash
.\detector.exe <countCircles> <minRadius> <maxRadius> <minContrast> <maxContrast> <blur>
```

Где:
- `<countCircles>` - количество кругов на изображении (по умолчанию 10),
- `<minRadius>` - минимальный радиус кругов (по умолчанию 5),
- `<maxRadius>` - максимальный радиус кругов (по умолчанию 15),
- `<minContrast>` - минимальный контраст кругов (по умолчанию 50),
- `<maxContrast>` - максимальный контраст кругов (по умолчанию 255),
- `<blur>` - уровень размытия (по умолчанию 4).

Также можно запустить исполняемый файл и настроить параметры в самой программе.

### Вывод

В ходе работы над лабораторной работой было продемонстрировано, что использование метода Ниблака для бинаризации изображений позволяет более эффективно детектировать объекты по сравнению с другими методами. Результаты анализа FROC показали, что количество истинно положительных ответов увеличивается при повышении порога IoU, что подтверждает эффективность предложенного алгоритма детектирования.
